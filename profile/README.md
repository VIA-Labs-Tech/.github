VIA Labs is a cross-chain messaging protocol that connects EVM and non-EVM blockchains natively. We pass data between smart contracts on different chains. What gets built on top, whether bridges, DEXs, marketplaces, or oracle feeds, is up to the developer.

150+ networks. 20M+ messages delivered. 4+ years in production. Zero exploits.

## Build

Inherit one contract, override one function, send messages between chains.

- [Hello World](https://developer.vialabs.tech/docs/examples/hello-world): your first cross-chain message
- [Token patterns](https://developer.vialabs.tech/docs/examples/burn-mint-token): burn and mint, lock and release
- [Private oracle](https://developer.vialabs.tech/docs/examples/private-oracle): deliver off-chain data to any chain
- [Cardano](https://developer.vialabs.tech/docs/examples/cardano/overview), [Midnight](https://developer.vialabs.tech/docs/examples/midnight/overview), and [Stellar](https://developer.vialabs.tech/docs/examples/stellar/overview): build on non-EVM chains
- [Transfer USDM: Cardano ↔ Midnight](https://developer.vialabs.tech/docs/examples/guides/usdm-cardano-midnight): move USDM between Cardano and Midnight
