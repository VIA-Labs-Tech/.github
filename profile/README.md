## 🌉 What is VIA?

VIA is a cross-chain message protocol. A transfer is submitted on a source chain, confirmed, attested by a decentralized validator set, and delivered on the destination chain — with every step publicly trackable on [VIA Scan](https://scan.vialabs.tech).

**Currently bridging:** Cardano (preprod) · Midnight · Avalanche Fuji — with more chains on the way.
